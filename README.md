# 🧩 Task Builder with React Flow

A visual task builder application built with **React Flow**, **Redux Toolkit**, and **Tailwind CSS**. This tool allows users to create, edit, and connect tasks on a canvas with persistent state and responsive UI.

---

## ✨ Features

- 🧱 Add tasks to the canvas
- ✏️ Edit task names in the node or via the sidebar
- 🔗 Connect tasks with edges
- 💾 Persist state in `localStorage`
- 📱 Responsive design for mobile and desktop

---

## 📦 Prerequisites

Make sure you have the following installed:

- **Node.js** (v16 or higher)
- **npm** or **yarn**

---

## 🚀 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/task-builder-reactflow.git
   cd task-builder-reactflow
   ```

2. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

---

## 🧪 Running the Application

Start the development server:

```bash
npm run dev
# or
yarn dev
```

The application will be available at [http://localhost:5173](http://localhost:5173).

---

## 🏗️ Building for Production

Build the application:

```bash
npm run build
# or
yarn build
```

Production files will be generated in the `dist/` folder.

---

## 🧹 Linting

Run the linter to check code quality:

```bash
npm run lint
# or
yarn lint
```

## 🛠 Technologies Used

- **React** – UI library
- **React Flow** – Node-based interface builder
- **Redux Toolkit** – State management
- **Tailwind CSS** – Utility-first styling
- **Vite** – Fast development and build tool
